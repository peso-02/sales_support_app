# 営業支援システム（Sales Support App）

## アプリケーション名
営業支援システム

## アプリケーション概要
営業アシスタントと営業担当者間の情報共有を円滑にするための業務支援システムです。  
得意先・仕入先・商品情報を一元管理し、営業活動をサポートします。

このアプリケーションでできること：
- 得意先情報の登録・編集・閲覧・CSV出力/インポート
- 仕入先情報の登録・編集・閲覧・CSV出力/インポート（担当者管理含む）
- 商品情報の登録・編集・閲覧・CSV出力/インポート
- 得意先ごとの商品単価管理
- ユーザー権限管理（一般/アシスタント/承認者/管理者）

## 利用方法
1. ログイン後、ダッシュボードから各機能にアクセス
2. 得意先管理
   - 新規登録ボタンから得意先情報を入力
   - CSV出力で一括エクスポート、CSVインポートで一括登録
   - 得意先名をクリックして詳細表示・編集
   - 詳細画面から商品単価一覧へアクセス可能
3. 仕入先管理
   - 新規登録ボタンから仕入先情報を入力
   - 詳細画面から担当者情報を複数登録可能
   - CSV出力/インポートで一括管理
4. 商品管理
   - 新規登録ボタンから商品情報を入力
   - A/B/C単価を設定
   - CSV出力/インポートで一括管理
5. 商品単価管理
   - 得意先詳細画面から「商品単価を見る」をクリック
   - 全商品に対する得意先別の販売単価を一覧表示
   - 未設定の商品は「単価設定」ボタンから登録可能

## アプリケーションを作成した背景
営業アシスタントとして勤務していた際、得意先ごとに異なる支払条件や出荷ルール、商品単価などの情報管理が煩雑で、営業担当者との情報共有に課題を感じていました。

**解決したい課題**：
- 得意先ごとの複雑なルール（締日、支払サイト、ケース割れ可否など）を素早く確認できない
- 商品単価が得意先によって異なり、都度確認が必要
- 情報がExcelやメモに散在し、最新情報の把握が困難
- 営業担当者が外出先から情報を確認できない

**解決策**：
システム化により情報を一元管理し、営業とアシスタント間の情報共有を円滑化。  
将来的にはスマホ対応により、外出先からのアクセスも可能にする。

## ローカルでの動作方法
```bash
# リポジトリをクローン
git clone https://github.com/peso-02/sales_support_app.git
cd sales_support_app

# 依存関係をインストール

# データベースを作成・マイグレーション

## 工夫したポイント

### 1. 実務経験に基づいた設計
- 営業アシスタントの実務経験から、本当に必要な機能を厳選
- 支払条件の表示方法など、実務で使いやすい形式を採用

### 2. CSV出力/インポート機能
- 既存データの移行を考慮し、CSV連携を実装
- バリデーション機能により、誤データの登録を防止

### 3. 商品単価一覧の設計
- 全商品を表示し、未設定商品を可視化
- 設定済み/未設定が一目で分かるUI

### 4. 権限管理の実装
- 将来のマニュアル承認フローを見据えた設計
- enumによる役割管理で拡張性を確保

### 5. ユーザビリティ
- Bootstrapによる統一感のあるデザイン
- 操作列を削除し、名前クリックで詳細遷移というシンプルな導線

## 改善点
